# What's new?
## 1.0.6
 - First release, for VotV 0.9 and 0.10. One package for both; it detects the game version itself.
 - Keeps the game's own item icons cached, so a mod change only renders the modded icons.
 - Main menu hints for loaded and rendered icons, game and modded listed separately (can be turned off).
 - On a VotV version it does not support yet, it shows a warning and changes nothing.
